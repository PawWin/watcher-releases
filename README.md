# Watcher

Download Watcher for Linux and Windows from [the latest release](https://github.com/PawWin/watcher-releases/releases/latest).

- **Linux:** download `Watcher.AppImage`, make it executable, and keep it in a writable folder under that name. Updates replace it at the same path.
- **Windows:** use the setup installer to enable in-app updates. Portable and zip builds are also available for manual installation.

Watcher checks for updates after startup and every six hours. Updates download in the background; choose **Restart to update** when ready.

This repository contains downloads and update metadata. Watcher's source repository is private.
